Privacy policy

This document describes the current implementation of DA Invoice Automation V4, a private internal tool operated by Daniel for DA Lawn Care Solutions.

Google data accessed

The app reads selected ledger, client and contact records. These can contain job dates, service descriptions, client names and addresses, invoice numbers, invoice amounts and payment status. It reads spreadsheet metadata, formulas and validation settings to check safe processing. It reads accessible Drive invoice names and file metadata, and downloads candidate invoice files for integrity and duplicate checks.

Purpose and use

Data is used to prepare DA invoices, validate their content, prevent duplicates, verify file integrity and update the configured ledger's invoice links and creation status. The app does not send customer emails or messages and does not change recorded payment status. The V4 workflow does not send Google data to generative AI models.

Storage and service providers

Source records remain in Google Sheets. Generated invoices are stored in the configured Google Drive folder. Code and run evidence are processed by GitHub Actions in the private automation repository. The existing manual workflow retains its invoice test artifacts for one day. The workflow does not implement automatic deletion of source records or Drive invoices; these remain under operator control.

Credentials and access

The intended unattended setup stores dedicated OAuth credentials as an encrypted GitHub Actions secret and refreshes access tokens during a run. Credentials are not included in these pages, invoice images or committed source. Runtime API errors are redacted. Access to the private repository and business records is governed by their existing Google and GitHub permissions.

Disclosure

The workflow uses Google and GitHub to provide invoice processing. It does not sell Google user data, provide it to advertising systems, or use it for model training. The operator decides whether and how to send verified invoices to their intended recipients outside this automation.

Revocation, correction and deletion

The operator can revoke Google access through their Google Account's third-party connections settings and remove the GitHub authentication secret. Revocation stops further authorized processing but does not delete existing ledger records, invoices or retained run artifacts. Corrections and deletion requests are handled by the business operator through the source records and storage systems.

Contact

Contact the DA Lawn Care Solutions operator using the support email displayed on this app's Google consent screen.
